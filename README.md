# سیستەمی بەڕێوەبردنی کافتریا و چێشتخانە (POS & Waiter Hub)

سیستەمی پێشکەوتووی کاشێر، مێزەکان، تابلێتی گارسۆن لە ڕێگەی QR، کۆنترۆڵی بەشەکانی نێرگەلە، ساردی و چێشتخانە، چاپکردنی LAN و داهاتی ڕۆژانە بە زمانی کوردی.

---

## 🚀 چۆنیەتی دروستکردن و داگرتنی فایلی ئینستالی EXE لە ڕێگەی GitHub

سیستەمەکە بە تەواوی ئامادە کراوە بە شێوەیەکی خۆکار بە **GitHub Actions**؛ هەموو جارێک کە کۆدەکە دەخەیتە سەر GitHub، فایلی ئینستالی ویندۆز (`.exe`) بە خۆکاری دروست دەبێت!

### هەنگاوەکان:
1. **کۆدەکە بخەرە ناو ڕیپۆزیتۆری GitHubەکەت (Push to GitHub)**:
   ```bash
   git add .
   git commit -m "سیستەمی کافتریا"
   git push origin main
   ```

2. **کردنەوەی بەشی Actions لە GitHub**:
   - لە لاپەڕەی پڕۆژەکەت لەسەر وێبسایتی GitHub، بچۆ بەشی سەرەوە و کلیک لەسەر **«Actions»** بکە.
   - ئەکشنێک دەبینیت بە ناوی **`Build Windows Installer (.EXE)`** کە لە حاڵی دروستکردندایە (ڕەنگی زەرد دەسوڕێتەوە تا دەبێتە سەوز ✔️).
   - هەروەها ئەگەر خۆت ویستت بە دەستی لێیبەیت، تەنها کلیک لەسەر **Run workflow** بکە.

3. **داگرتنی فایلی Setup .EXE بۆ سەر لاپتۆپەکەت**:
   - کلیک لەسەر نوێترین Build بکە.
   - لە بەشی خوارەوە (بەشی **Artifacts**)، فایلی **`Cafeteria-POS-Windows-Setup-EXE`** دەبینیت.
   - کلیکی لێ بکە بۆ داگرتن، فایلێکی زیپ دابەزێت کە لە ناویدا فایلی ئینستالی تەواوە:
     `Cafeteria POS Hub Setup 0.0.0.exe`

4. **دامەزراندن لەسەر لاپتۆپ (Install)**:
   - دوو کلیک لەسەر فایلی `.exe` بکە؛ سیستەمەکە ڕاستەوخۆ دەبێتە بەرنامەی فەرمی و شۆرتکەت دەچێتە سەر دێسکتۆپ و وەک بەرنامەیەکی فەرمی کار دەکات بێ پێویستی بە وێبگەڕ یان ئینتەرنێت.

---

## 💻 تاقیکردنەوە و دروستکردنی لۆکاڵی لەسەر کۆمپیوتەرەکەت (Local Build)

ئەگەر Node.js لەسەر کۆمپیوتەرەکەت دامەزراوە، دەتوانیت لە تێرمیناڵ بەم فەرمانە لۆکاڵیش دروستی بکەیت:
```bash
# ١. دامەزراندنی پێداویستییەکان
npm install

# ٢. بەرهەمهێنانی فایلی EXE بە یەک فەرمان
npm run electron:build
```
فایلی ئینستالەکە لەناو بوخچەی `dist-electron` دروست دەبێت.
